# Telegram VPS Manager Bot

بوت تيليجرام عربي لإدارة ومراقبة الخوادم (VPS) بأمان. مبني باستخدام Node.js و TypeScript.

## الميزات (Features)
- مراقبة حالة الخادم (المعالج، الذاكرة، القرص، مدة التشغيل).
- فحص حالة الخدمات (Nginx, Docker, PM2, SSH, UFW).
- قراءة وعرض الملفات ضمن مسارات مسموحة فقط (للحماية).
- إعادة تشغيل أو إعادة تحميل Nginx.
- تنبيهات تلقائية عند تجاوز الحد المسموح من الاستهلاك.
- حماية ضد الوصول غير المصرح به (مقتصر على حساب تيليجرام واحد).

## الإعداد (Setup)
### 1. الحصول على توكن البوت (Bot Token)
- اذهب إلى تيليجرام وابحث عن `@BotFather`
- أرسل له أمر `/newbot` واتبع التعليمات.
- سيتم إعطاؤك رمز (Token) مشابه لهذا: `8916778627:AAEF-5GM3uRh4xoJWwm3l1UcOevGV9EA6EM`

### 2. الحصول على مُعرّف المستخدم (Telegram Admin ID)
- اذهب إلى تيليجرام وابحث عن `@userinfobot` أو `@raw_data_bot`
- أرسل أي رسالة وسيتم الرد عليك بـ ID الخاص بك (مثال: `8271446629`).

### 3. إعداد البيئة (Environment Variables)
انسخ ملف الإعدادات وقم بتعديله:
```bash
cp .env.example .env
```
افتح ملف `.env` وقم بتحديث `TELEGRAM_BOT_TOKEN` و `TELEGRAM_ADMIN_ID` وبقية الإعدادات كما يناسبك.

## التشغيل محلياً (Local Run)
```bash
npm install
npm run dev
```

## النشر والاستضافة (VPS Deployment)
تم توفير خطوات نشر كاملة للخادم عبر ملف `DEPLOYMENT.md`. اقرأ الملف لمعرفة كيفية تشغيل البوت في الخلفية باستخدام PM2.

## أوامر PM2 الأساسية
- تشغيل البوت: `pm2 start dist/index.js --name vps-bot`
- عرض الحالة: `pm2 status`
- عرض السجلات (Logs): `pm2 logs vps-bot`
- إيقاف البوت: `pm2 stop vps-bot`
- حفظ الإعدادات لتعمل بعد إعادة التشغيل: `pm2 save`
